项目简介

中文 AI 求职助手，帮助用户建立个人履历库、生成母简历、匹配 JD、一键转英文。前后端分离架构：React + TypeScript 前端 (Vite)，FastAPI + Python 后端。

功能清单

页面 1：个人资料 (Welcome)

  • 中文表单：姓名、求职意向、邮箱、电话、出生年月、最高学历、学校、专业、学位、在校时间、自我介绍
  • 自动保存：停止输入 2 秒后自动调用 saveProfile 写入 data/profile.json
  • 导出 JSON 按钮：下载 profile.json 文件
  • 导入 JSON 按钮：选择文件恢复 profile

页面 2：AI 对话 (Chat)

  • 8 阶段引导式对话：基本信息→自我介绍→工作经历→技能→教育→项目经验→获奖→自我评价
  • 每个阶段完成后自动提取信息到 profile
  • 新建对话 / 历史会话下拉（最近 10 个）
  • 点击历史会话可恢复继续对话
  • 右侧阶段进度面板——点击任意阶段可跳转
  • 会话持久化到 data/sessions/{session_id}.json

页面 3：简历编辑器 (ResumeBuilder)

  • 编辑模式：
    • 8 个默认板块 + 自定义增删板块
    • 板块拖拽排序、标题可点击重命名
    • 基本信息：6 字段拖拽重新排列 + 照片上传/删除 + 自定义字段（键值对）增删
    • 自我介绍：富文本工具栏（加粗 B / 下划线 U / 字号选择 12-18px）
    • 个人技能：统一标签输入框（输入回车添加，点击 × 删除）
    • 工作经历：多条目列表，每条含公司/职位/时间 + 工作内容标签
    • 项目经验：多条目，含名称/时间/角色 + 技术栈 + 描述 textarea + 职责/成果标签
    • 教育背景：多条目列表（如本科+硕士），每条含学校/专业/学位/时间 + 课程标签
    • 获奖/自我评价：标签列表编辑器
    • 每个板块有「AI 润色」按钮，调用 DeepSeek 优化措辞
  • 预览模式：
    • 模拟真实简历排版：照片+姓名+联系方式→各板块按序展示
    • 点击任意板块/字段可切回编辑定位
    • AI 润色结果在预览中直接呈现
  • 工具栏：AI 润色全文 | 一键转英文 | 导出 MD/DOCX/PDF

页面 4：岗位匹配 (JDAnalysis)

  • 粘贴 JD 文本 → AI 解析（标题/公司/地点/技能/描述/要求）
  • 保存解析结果，匹配分析：总分 + 技能/经验/学历/偏好四项得分条
  • 优劣势分析 + 改进建议 + 需掌握技能
  • 一键生成定制子简历（针对该 JD 优化）

后端 API 端点

Chat 模块 backend

方法路径说明
POST/api/chat/start新建对话会话
POST/api/chat/message发送消息，AI 回复
GET/api/chat/sessions列出所有历史会话
POST/api/chat/session/{id}/resume恢复指定会话

Profile 模块 backend

方法路径说明
GET/api/profile获取当前 profile
PATCH/api/profile更新单个字段
PUT/api/profile/save全量保存 profile
POST/api/profile/extractAI 从对话中提取结构化信息
GET/api/profile/export导出 profile JSON

Resume 模块 backend

方法路径说明
GET/api/resume/draft生成简历草稿
POST/api/resume/polishAI 润色单个板块
POST/api/resume/polish-fullAI 润色全文
POST/api/resume/translate-to-english一键翻译简历为英文
GET/PUT/api/resume/layout简历布局配置
GET/api/resume-export/markdown导出 Markdown
GET/api/resume-export/pdf导出 PDF（HTML 模板渲染）
GET/api/resume-export/html导出 HTML（预览版式，可打印）

JD 模块 backend

方法路径说明
GET/api/jd列出所有 JD
POST/api/jd创建 JD
DELETE/api/jd/{id}删除 JD
POST/api/jd/parseAI 解析 JD 文本
GET/api/jd/{id}/matchJD 匹配分析
POST/api/custom-resume生成定制子简历

数据模型

ProfileData（简历数据核心模型）model

  • basic_info: name, job_intention, email, phone, birth_date, highest_degree, photo (base64), custom_fields ({key, value}[])
  • self_intro: string — 自我介绍
  • work_experiences: 工作经历列表（company_name, position_name, work_time, work_contents[]）
  • skills: string[] — 技能标签列表（已简化为单一数组）
  • education: 教育背景列表（school_name, major, degree, school_time, main_courses[]）— 支持多条
  • project_experiences: 项目经验列表（project_name, project_time, project_role, technologies[], project_description, personal_responsibilities[], project_results[]）
  • awards: string[] — 获奖
  • self_evaluation: string[] — 自我评价

AI 集成

DeepSeek API backend

  • 配置文件：backend/.env — 设置 DEEPSEEK_API_KEY 和 DEEPSEEK_MODEL
  • 服务类：backend/app/services/deepseek_service.py
  • 同时支持 OpenRouter 和 Groq 作为备选（通过 settings 切换）
  • 所有 AI 调用超时 60 秒

启动方式

后端

cd backend
python -X utf8 -m uvicorn app.main:app --host 0.0.0.0 --port 8000

注意：必须使用 -X utf8 标志以确保中文文件名和源代码正确解析。

前端

cd frontend
npm run dev (开发模式，端口 3000，自动代理 /api → 127.0.0.1:8000)

访问

前端：http://localhost:3000
后端 API 文档：http://localhost:8000/docs
